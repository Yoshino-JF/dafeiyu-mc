`!buildHouse("plains")` 会在她选好并走到的位置附近建房：原点是脚位向 X 加 3、Z 加 2，高度默认取该占地的地表中位数。也接受 `desert`、`savanna`、`snowy`、`taiga` 和 `plains_2` 等编号；加上 `igloo_basement`，目录共 38 种。

底层 `buildHouse(bot, style, {here:true})` 直接使用她选择的脚位高度，不扫描地表，也不向上强制打通天空。两种模式用同一套保护区和付款检查。地下建议 cave 或 igloo_basement，普通村庄房也可以在她选择的地下高度生成，不强制款式。

清理模板占用的空间，垫石质地基，再执行原版 `/place template`。默认模式从世界顶端读取已加载列，忽略树木作为地表，但把高柱/树冠的实际清理高度纳入保护盒；未知地面不回退到坑底。Here 模式只清房屋与上方 4 格。地基向下读取最多 32 格寻找支撑；没有观测到支撑时做 8 格厚基座，极端悬空/深水选址仍需要后续真实试玩。任何被清理或填充的区域碰到已登记保护区时不发命令；占地里有玩家时请其先移开。

材料是宽松的建房额度：以模板非空方块数的一半为上限，消耗她背包里的原木、木板或常见石材，不足部分由房屋额度补齐；不会给背包刷物品，也不会因缺材料而禁建。材料扣除只在服务器放置回执及房屋方块检查后进行。

成功后把门口记录到地点记忆 `home`，同时保存 `bots/<名字>/house.json`；`[act] kind:op-fill` 记录实际结果。中途取消或命令失败时说明原因，已清理或放置的部分不会自动回滚，便于她根据现场继续处理。
