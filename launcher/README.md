在项目根目录双击 **大肥鱼启动器.exe**，会打开一个独立窗口，不需要外部浏览器，也不需要大肥鱼自己的 Minecraft 客户端。

页面：
- **启程**：保留大肥鱼的 MC 冒险壁纸，显示当前连接、陪玩状态与启动入口。她在线时显示生命、饥饿、位置、时间、动作和最近一句话。
- **我的世界**：新建、导入、选择本地世界；调整模式、难度与端口；备份、恢复、归档和取回。支持搜索、备份历史与服务器启动状态。
- **连接**：服务器地址和端口、她的游戏用户名、你的游戏用户名（她会把这个名字当成主人）、控制端口（一般不用改）。
- **模型**：接口类型（DeepSeek 或 OpenAI 兼容）、API 地址、模型名、API Key。密钥输入框留空表示不修改原来的密钥。
- **语音**：播报和按住说话的开关、说话按键；播报和识别各自的接口、地址、模型、音色、密钥。
- **人设**：写在这里的内容追加到默认人设 `profiles/dafeiyu.json` 后面，默认人设本身不会被改动。“清空补充设定”保存后生效。
- **外观**：主页背景图，可以换成自己的图片，也可以恢复默认。
- **日志**：“对话”只显示她说的话，以及你从这里以你的名字发给她的话；“运行日志”是进程原始输出，密钥会被遮住。

修改设置后直接点启动，会先自动保存。关闭窗口时会先让她正常下线，再保存关闭本次启动器自己启动的本地世界。外部服务器仍由它自己的管理者保存和关闭。

### 新建与管理世界

1. 打开 **我的世界 → 新建世界**，填写名称，可选种子、生存/创造模式、难度和地形。高级设置可改端口、建筑生成和玩家间伤害。种子按文本保存，不丢失长整数精度。
2. 创建后自动设为当前世界。首次启动前需阅读并同意 Minecraft EULA；地形在首次启动时生成。
3. 回到 **启程 → 启动陪玩**，先启动本地服务器，等它真正就绪后再让大肥鱼进入。也可以在世界卡片上只点 **启动世界**。玩家用多人游戏连接卡片显示的 `127.0.0.1:端口`。
4. **停止陪玩** 只让大肥鱼下线，保留服务器给玩家。需要关服时先停止陪玩，再在世界卡片上点 **保存并停服**。关闭整个启动器也会按此顺序安全退出，不强杀进程。

**导入**：先正常关闭源游戏/服务器，选择包含 `level.dat` 的存档文件夹（填写完整路径），启动器复制到自己的目录；原存档不移动、不覆盖。不要复制正在写入的世界。导入不会复制原服务器的插件、模组或数据包依赖之外的服务端配置；有模组的世界需自行选择兼容核心。

**备份与恢复**：仅停服后操作。备份包含世界数据与世界设置，恢复前自动保存一份当前状态；失败会回滚。已有世界不能修改种子或地形。归档代替删除，存档和备份保留，可以取回。

根目录的文件布局：

```text
worlds/<世界ID>/          存档、server.properties、世界信息和日志
worlds/engine.json        共用服务器核心 / Java / 内存配置
world-backups/<世界ID>/   各次备份
worlds-archive/<世界ID>/  归档的世界
```

发布包自带服务器核心（`server/server.jar`，Paper）和 Java 25（`java/`，Temurin 精简运行时），新用户不用另装，也不用在**本地服务器设置**里改。第一次启动世界时会联网下载 Minecraft 官方服务器文件，在 `server/` 里准备一次（约 1–3 分钟）；之后每个世界直接从这里复制，不再下载。官方服务器文件不能随包分发，所以由 Paper 现场获取。也可以在**本地服务器设置**里换成自己的核心与 Java：自动查找 `server/server.jar`、`services/server/server.jar`，开发目录存在时也可复用 `dev/server/server.jar`。只复制核心的 `libraries` / `versions` / `cache` 运行依赖，既有测试服的世界、配置和 OP 不会被复制。本地世界仅监听 `127.0.0.1`，采用离线模式；启动时为配置里的大肥鱼及主人游戏名设置 OP，以支持已有的盖房和传送能力。新包若未附带服务器核心，请自行选择对应 Minecraft 版本的 server.jar 与 Java。

切换回外部服务器请在 **服务器连接** 中改连接方式。选择本地世界前的外部地址会保留，切回时自动恢复。

服务器需要给她管理员权限，她才能用一键盖房和传送到玩家身边。死亡不掉落（`keep_inventory`）由服务器管理者自己决定开不开。启动前，同一个名字不能已经在线：启动器会检查 8091 上的会话，有的话就拒绝启动，不会去关别人的进程。

配置文件在项目根目录：`launcher.settings.json` 和 `keys.json`。她运行时的人设生成在 `runtime/launcher/profile.json`。文字模型的调用代码在 `src/models/`，语音在 `src/voice/`，语音参数的说明见 `docs/VOICE.md`。

启动器使用自己的控制端口 **8092**，和开发调试用的 8091 分开。她的进程不设内存上限，和开发测试时的跑法一致。

开发入口：`node launcher/server.mjs --no-open`。

构建：`powershell -File launcher/build-exe.ps1`。构建需要的 WebView2 组件在 `launcher/vendor/webview2/`。请保留整个项目目录，不要只复制 EXE。

界面自检：`大肥鱼启动器.exe --ui-smoke`，结果写在 `runtime/launcher/native-ui-smoke.json`。

世界文件与退出竞态测试：`node22/node.exe --test launcher/worlds.test.mjs`。浏览器端到端验证：配置 `LAUNCHER_TEST_NODE_MODULES` 指向装有 Playwright 的 node_modules 后运行 `node22/node.exe launcher/launcher-ui.test.mjs`，会在 `dev/gpt-launcher-worlds-20261028` 下生成独立测试目录。该测试会启动独立本地服务器，不启动陪玩或调用模型；不要拿生产配置目录作测试目录。
