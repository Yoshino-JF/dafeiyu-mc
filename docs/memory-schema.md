# 记忆 S 版 schema（大肥鱼 · 单 AI）

> 设计目标：**她能记住「发生过什么」和「学到了什么」**，而且每条都有字数上限 —— 因为要每天塞进提示词。
> 原则：**人写的部分她自己写，机器写的部分不许她改。** 分开存放，才能验"她说的和做的一样"。

## 0. 已知限制：taught 事实的去重（2026-10-26）

同一件事会被每个黎明用不同措辞再 promote 一次。现在的去重顺序是：**先语义（qwen embedding，同人 + 余弦 ≥ 0.78 + 地点守卫），失败或无嵌入模型时退回字面/话题规则**（字二元组包含度 ≥ 0.50，或话题签名互相覆盖）。

**限制（一行）**：语义去重尚未默认开启 —— 它依赖 profile 的 `embedding` 模型可用（10-30 起 `profiles/dafeiyu.json` 不再配嵌入模型，发布版只用 DeepSeek，所以默认走字面/话题规则；阈值是当时用 qwen `text-embedding-v3` 测的）；没有嵌入模型时只剩字面/话题规则，而话题词典（住上面/跳起来放方块/睡觉/箱子/食物）是按今晚几条事实手写的，**换一个主人的事实就不适用**（开源前必须替换成通用判据，或确保嵌入可用）。

## 1. 目录

```
dafeiyu-mc/memory/
  identity.md          ← 出厂自带（我写，只读给她看）：她是谁、规矩、她在哪儿写什么
  self.md              ← 她自己的长期自我认知（她自己每天重写，≤ 2 KB）
  goals.md             ← 这几天的目标（她自己写，可随时改，≤ 1 KB）
  lessons.md           ← ★ 失败教训（机器在失败时追加，她每晚可整理，≤ 4 KB）
  places.md            ← 地点簿（名字 → 坐标；机器在保存时追加）
  people.md            ← 关系（主人的偏好、其他玩家；她自己写，≤ 2 KB）
  story/
    day-001.md …       ← 每日日记（她自己写，append-only，≤ 2 KB/天）
  raw/
    day-001.jsonl      ← 机器原始记录（决策/动作/聊天，不裁剪，供审计）
  state.json           ← 机器状态（当前目标、上次失败、上次进食、忠诚度等）
```

**为什么要 `raw/` 与 `story/` 分开**：日记是**她自己讲的**，raw 是**客观发生的**。两者能对上，才说明她没瞎编。

## 2. 每个文件的写入者与时机

| 文件 | 谁写 | 何时 | 上限 |
|---|---|---|---|
| `identity.md` | 我（出厂） | 一次 | 2 KB |
| `self.md` | 她 | 每晚结束（1 次 LLM 调用） | 2 KB |
| `goals.md` | 她 | 每天早上 + 目标达成/放弃时 | 1 KB |
| `lessons.md` | **机器追加**（失败时）+ 她每晚整理 | 每次 `act.ok:false` | 4 KB |
| `places.md` | 机器 | 她"记住这个地方"时 | 2 KB |
| `people.md` | 她 | 每晚（若当天有互动） | 2 KB |
| `story/day-NNN.md` | 她 | 每晚 | 2 KB |
| `raw/day-NNN.jsonl` | 机器 | 持续 | 不裁剪 |
| `state.json` | 机器 | 持续 | — |

## 3. `lessons.md` 的条目格式（这是"自我学习"最小可用形态）

```md
- [3天前] 在茂密林地里 goto 失败（no_path）3 次 → 后来改成先走到开阔处再走，成功
- [昨天] 挖铁矿时没有镐（need_tool）→ 下次先确认手上有镐
- [今天] 夜里在户外挖石头被僵尸追 → 天黑前回屋
```

**规则**：
1. 机器在 `act.ok:false` 时**自动追加一行**（`[时间] 动作 + reason + 参数摘要`），**不超过 2 行**；
2. 她每晚可以**合并/重写**成人类可读的一句话（这是"她学到的东西"）；
3. 注入提示词时**最新的在前**，超过 4 KB 时**丢最旧的**（并且她知道会被丢，所以要把重要的写进 `self.md`）。

## 5. 每天提示词里塞什么（总预算 ≤ 12 KB）

| 块 | 来源 | 预算 |
|---|---|---|
| 人设 | `profiles/dafeiyu.json` 的 `conversing` | 7 KB（固定） |
| 记忆摘要 | `self.md` + `goals.md` 末尾 5 行 | 2 KB |
| 教训 | `lessons.md` 最新 6 条 | 1 KB |
| 环境 | 位置 / 时间 / 血量 / 背包 / 附近 | 1.5 KB（`$STATS` `$INVENTORY` 自带） |
| 关系 | `people.md` 里主人那一段 | 0.5 KB |

**超预算就砍教训，不砍人设** —— 人设是她"是谁"，教训是"技巧"，技巧可以被重新发现。

## 6. 怎么验她没瞎编（我这边做）

1. `story/day-NNN.md` 里提到的动作，必须在 `raw/day-NNN.jsonl` 里有对应的 `[act] ok:true`；
2. 对不上 ⇒ `said-not-done`（WARN）；连续 3 天 ⇒ FAIL 级证据；
3. `lessons.md` 里写的 reason，必须在 raw 里真实出现过（防"编造成因"）；
4. `places.md` 的坐标必须与当时的 `[act]` 坐标一致（防"记错家在哪"）。
