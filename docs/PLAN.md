# 大肥鱼 MC 陪玩：新项目方案（定稿，2026-10-25）

GPT（#2934）和 DeepSeek（#2933、#2937）复核过，三方意见一致；Claude 牵头，分工由主人授权 Claude 安排。

## 一、为什么重做，这次怎么保证不做白工

过去两周原地踏步，原因有三个：

1. **底子不对。** 她靠模拟按键操作真实客户端，每个动作都要绕好几层。一层出错就补一条规则，两周补了约 300 条，规则之间还会互相打架。
2. **测的地方不对。** 一直在测试世界里验收；测试世界里能通过，到主人的正式环境就走不通。
3. **目标测歪了。** 测的是"剧情有没有按脚本走完"，而不是"像不像一个自由的人"。

这次的五条铁律：

1. **能用现成的就用，不好的再改，不重复造轮子（主人原话）。** 每加一样东西，都必须能对上下面需求清单里的一条，对不上就不做。
2. **主人试玩就是验收。** 开发和测试都在主人服务器的副本上做，每天给主人试玩一小段。只保留几分钟的冒烟测试，用来防止改坏旧功能，不再造测试世界、跑脚本剧情来验收。
3. **不写场景规则，也不替她保命。** 代码里只留保护别人的规矩（D）；其他一律变成她能看到的事实，比如上次为什么失败、怎么死的、手里有没有武器、主人在哪，由她自己选、自己吸取教训。
4. **自由程度要能量化。** 从第 1 天起就记两种日志，格式按 DeepSeek #2929 先定好：
   - `[decision]`：有哪些选项、选了哪个、为什么；没有明确候选项时如实记"未提供"，不编造。
   - `[act]`：做了什么、成没成、失败原因（固定的几类）、试了几次、改用了什么办法。

   DeepSeek 用这两种日志算出固定台词占比、可选项数量、停摆次数等数字。
5. **证据说准。** 能验证的说已验证，没验证的说未验证。版本要锁定：记下所用 Mindcraft 的具体提交，以及 mineflayer 的精确版本和依赖锁文件，不跟着官方最新版漂移。

## 二、选型结论

- **身体：** 无头机器人，用 mineflayer 4.39.0。
  - **已验证：** 在私有的 Paper 26.1.2 副本上，以下动作都通过了：连接、聊天、管理员命令、寻路、挖方块并捡起、合成、放方块、开箱子、打僵尸、晚上睡觉。
  - **还没验证：** 在主人的真实存档里、在完整的 Mindcraft 上跑。茂密林地里寻路偏弱。
  - 主人已同意不需要客户端画面。
- **底子：** 基于官方 Mindcraft（MIT 许可）新建，锁定一个具体提交。
  - 它已经有：对话加命令的循环、技能库、模型现写新动作（`!newAction`）、自己定目标（`!goal`）、只管保命的反射开关（modes）、记忆。
  - 官方只标到支持 1.21.11，适配 26.1 留了风险时间，不是只升级一个包就能保证。
  - 大肥鱼最早就是在 Mindcraft 上做的，人设文件 `neko.json` 的内容可以复用，但格式要按新版改写。
- **第二轮调研：** 比较了 Mindcraft-CE、Odyssey、Voyager、MineLand、PlayerEngine / Player2NPC、airi-minecraft，Mindcraft 仍然最合适。其他几个的问题是：
  - 停更、归档，或只支持 1.19–1.21.1；
  - 是 Fabric / Forge 模组，在 Paper 上跑不了；
  - 是研究项目，不是陪玩。

  Mindcraft-CE 里还没合进官方的补丁可以按需挑着用。
- **照搬的做法（需求 H）：**
  - **技能库：** 每个技能一个 JS 文件，配一段描述，按描述检索最相关的技能。
  - **先查再入库：** 判断成功看真实的背包或世界变化，成功了才存成技能。
  - **两层技能：** 学会的组合技能只能调用人写的基础技能。
  - **自动课程：** 记下做成的和失败的任务，供她自己定目标时参考。
  - **待查：** Mindcraft 现在会不会保存现写的动作。动手前先看源码，再决定这块是自己做还是复用。
  - **从 AIMC 借鉴：** 执行前先检查动作格式；失败后重试，做不到就降级；关系记忆。
- **不选的方案：**
  - AIMC：只能从 8 个固定技能里挑；只有 2 个星；只支持 1.20；许可证不清楚。
  - Player2 / Steve AI：不支持 26.1。
  - Citizens：不会挖、不会合成。

## 三点五、不用客户端，怎么知道测得如何

1. **主人进服亲眼看。** 这是主要的验收方式。她作为普通玩家出现在服务器上，主人用自己的客户端进服就能看到她。默认是 Steve 或 Alex 的皮肤，要换大肥鱼的皮肤，得在服务器上装 SkinsRestorer 插件，这算改服务器，需要主人同意。
2. **浏览器 3D 画面。** 用 prismarine-viewer 实时看她的视角，在 26.1.2 上能不能用还没测，第 1 天顺手试。
3. **她自己的记录。**
   - `[decision]` 和 `[act]` 日志；
   - 每日日记；
   - DeepSeek 的自由度审计数字，包括固定台词占比、停摆次数、一天做了几种事。
4. **假玩家当测试主人（主人 2026-10-25 授权，需要就用）。** 在开发副本上再开一个 mineflayer 机器人扮演主人：跟她聊天、走开、打她、叫她睡觉、给她东西，不用每次都等主人。Paper 上用不了 Carpet 的 /player；需要时也可以在副本上装 Paper 的假玩家插件。用假玩家测出来的结果不能代替主人试玩。
5. **开发时的自动检查。** 读服务器日志和她的状态（位置、血量、背包、当前目标）。需要看画面时，GPT 开一个最小化的旁观客户端截图，不打扰主人。
